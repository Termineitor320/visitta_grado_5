# Paso a paso — Visita estudiantes grado 5

## Objetivo


## Materiales y herramientas
- Computador con Windows.
- Visual Studio Code.
- Google Chrome, Microsoft Edge o Firefox.
- Conexión a Internet.
- Git y una cuenta de GitHub para publicar/guardar el proyecto.
- Google Meet para la presentación posterior.
- Capturas de pantalla como evidencia.

## Distribución de la hora

### 1. Introducción — 5 minutos
Explicar qué es una página web y presentar el resultado que se construirá.

### 2. Crear la carpeta — 5 minutos
Crear una carpeta llamada `visita_estudiantes_grado5`.
Dentro crear:
- `sitio_web`
- `evidencias`

Abrir la carpeta principal con Visual Studio Code.

### 3. Crear el HTML — 15 minutos
Dentro de `sitio_web`, crear `index.html`.
Explicar de manera sencilla:
- `<!DOCTYPE html>`: indica que usamos HTML5.
- `<html>`: contiene la página.
- `<head>`: información de configuración.
- `<title>`: título de la pestaña.
- `<body>`: contenido visible.
- `<h1>` y `<h2>`: títulos.
- `<p>`: párrafos.
- `<ul>` y `<li>`: listas.
- `<button>`: botón.

El estudiante debe cambiar el título y escribir algunos gustos propios.

### 4. Crear el CSS — 15 minutos
Crear `style.css`.
Explicar que CSS sirve para cambiar la apariencia.
Modificar junto con el estudiante:
- Color del fondo.
- Color de los títulos.
- Tamaño y tipo de letra.
- Espaciado.
- Bordes redondeados.
- Apariencia del botón.

### 5. Probar y corregir — 10 minutos
Abrir `index.html` en el navegador.
Comprobar que:
- El texto aparezca correctamente.
- Los estilos de CSS funcionen.
- Los cambios realizados por el estudiante se vean en pantalla.

Tomar capturas de pantalla del proceso como evidencia.

### 6. Cierre — 10 minutos
Preguntar al estudiante qué aprendió.
Explicar brevemente la diferencia:
- HTML = estructura y contenido.
- CSS = diseño y apariencia.

Guardar todos los archivos y dejar el proyecto listo para GitHub.

## Presentación por Google Meet
El estudiante debe mostrar su página y explicar:
1. Qué página creó.
2. Qué elementos agregó con HTML.
3. Qué cambios de diseño hizo con CSS.
4. Qué fue lo que más le gustó.
5. Qué aprendió durante la actividad.
